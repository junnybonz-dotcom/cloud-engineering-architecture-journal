* **July 31 (Day 8)** This day I learn about mastering the octal notation formula for security mappings. In Python, iterate across server list structures using for loops.

`LINUX:`

Every file/directory has three permission sets: owner, group, others — each can have `r (read), w (write), x (execute)`.
Each permission has a numeric value: `r = 4, w = 2, x = 1`. No permission = `0`.
Add the values together per set to get one digit: `rwx = 4+2+1 = 7, rw- = 4+2 = 6, r-x = 4+1 = 5, r-- = 4`.
Three digits together = owner, group, others. `755 = owner rwx, group r-x, others r-x. 644 = owner rw-, group r--, others r--`.
`chmod 755 file` — sets those exact permissions on `file`.

touch deploy.sh
chmod 755 deploy.sh
ls -l deploy.sh
# -rwxr-xr-x  1 yourname staff  0 Jul 31 09:00 deploy.sh
# owner: read/write/execute, group: read/execute, others: read/execute

touch secrets.env
chmod 600 secrets.env
ls -l secrets.env
# -rw-------  1 yourname staff  0 Jul 31 09:05 secrets.env
# owner: read/write only, group and others: nothing at all

chmod 644 config.json
ls -l config.json
# -rw-r--r--  1 yourname staff  128 Jul 31 09:10 config.json
# owner can edit, everyone else can only read

`PYTHON:`

`for item in list`: — runs the loop body once per item, automatically pulling out each value in order. No manual indexing needed — you don't write `list[i]`, the loop hands you `item` directly.
`for i, item in enumerate(list)`: — same thing, but also gives you the index alongside the item, when you need both.

hostnames = ["web-01", "web-02", "db-primary", "cache-01"]

for host in hostnames:
    print(f"Pinging {host}...")

    # with enumerate, when you need the position too
for i, host in enumerate(hostnames):
    print(f"{i}: {host}")
# 0: web-01
# 1: web-02
# 2: db-primary
# 3: cache-01

# a loop that actually does something with each item
permissions = [755, 644, 600, 777]

for perm in permissions:
    if perm == 777:
        print(f"{perm}: WARNING — world-writable!")
    else:
        print(f"{perm}: looks fine")

`REAL WORLD USE: Octal notation is what you'll type constantly once you're managing real servers — SSH private keys must be 600 or SSH refuses to use them, web server files are typically 644, and executable scripts need that x bit (755) or you'll get "permission denied" trying to run them. 777 (everyone can read/write/execute) is a classic security red flag you'll be trained to spot on sight.for loops over lists are how you process a whole fleet instead of one server at a time — checking every host's status, applying a config change to every instance in a pool, or scanning a list of permission values for anything dangerously open, exactly like the example above.`
