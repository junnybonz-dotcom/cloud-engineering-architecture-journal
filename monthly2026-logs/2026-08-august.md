## 🛠️ How I Solved Problems (My Debugging Process)

* **Script Execution Permissions:** Shell scripts failed on execution with `Permission Denied`. Resolved by updating file modes using `chmod +x <script_name>.sh`.
* **Cron Path Failures:** Cron jobs failed silently because relative paths weren't recognized in automated background environments. Resolved by specifying absolute system tool paths (e.g., `/usr/bin/python3`).
* **CLI Parameter Validation:** Scripts broke when running via `sys.argv` without terminal input arguments. Fixed by wrapping CLI input reads inside `try`/`except IndexError` blocks.
* **Environment Secrets Protection:** Avoided pushing API credentials and sensitive variables to GitHub by organizing configurations into `.env` files and managing system reads via `os.environ`.
